# K线记账支持页面

这个仓库用于托管「K线记账」的 App Store 支持页面、隐私政策和使用条款。

## 页面状态

支持邮箱、隐私政策中的开发者主体名称，以及页面之间的正式链接均已填写。

完成替换后，Apple App Store Connect 中使用：

- `support.html` 作为技术支持网址
- `privacy-policy.html` 作为隐私政策网址
