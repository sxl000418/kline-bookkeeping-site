# K线记账支持页面

这个仓库用于托管「K线记账」的 App Store 支持页面、隐私政策和使用条款。

## 上线前需要替换的占位符

- `[支持邮箱]`：替换为真实支持邮箱
- `[开发者姓名或公司全称]`：替换为版权/隐私政策中的实际权利人
- `[隐私政策URL]`：替换为 GitHub Pages 发布后的隐私政策地址
- `[支持页面URL]`：替换为 GitHub Pages 发布后的支持页面地址

完成替换后，Apple App Store Connect 中使用：

- `support.html` 作为技术支持网址
- `privacy-policy.html` 作为隐私政策网址
